    Envoi par WhatsApp

    Numéros maliens uniquement (8 chiffres) — +223 est ajouté automatiquement. Tape le numéro ou choisis-le dans la liste (numéros déjà utilisés sur cet appareil). Le numéro est retenu pour la personne qui paie.
    Avec un numéro : le PDF se télécharge et la discussion WhatsApp de ce numéro s'ouvre avec le message déjà écrit — joins le PDF (trombone → Document) puis envoie. Sans numéro : sur mobile le PDF est joint directement et tu choisis le contact ; sur ordinateur WhatsApp Web s'ouvre.
